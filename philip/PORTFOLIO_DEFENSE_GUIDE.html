1. The 1-Minute Elevator Pitch

"Good day, Sir/Ma'am! This is my personal portfolio website, designed to showcase my identity, skills, and projects as an aspiring Web Designer and Full-Stack Developer.

Architecturally, it is built with zero external dependencies using pure semantic HTML5, modern CSS3, and Vanilla JavaScript (ES6+). It follows a clean Separation of Concerns where all content is decoupled into a dedicated data store (js/data.js), allowing instant updates without modifying HTML templates. It is fully responsive, accessible, supports persistent Dark and Light themes, and highlights my capstone work like NUMIFY—my Django and PostgreSQL numeracy assessment platform."

2. Step-by-Step Presentation Script (3–5 Minutes)

Step 1: Introduction & Philosophy

"The goal was to create a fast, accessible, and high-performance showcase. Instead of heavy libraries like React or Bootstrap, I chose pure vanilla web standards to ensure instant load times and show my mastery over core web fundamentals."

Step 2: Architecture & Structure

  • Content Layer (js/data.js): Stores all projects, highlights, skills, and awards as a single source of truth.
  • Interaction Layer (js/main.js): Dynamically renders DOM elements, manages event delegation, and handles user actions.
  • Styling Layer (css/styles.css): Leverages CSS Variables (Custom Properties) for instantaneous Dark/Light theme switching.

Step 3: Interactive Features Walkthrough (Screen Demo)

  1. Hero Section: Dynamic role typing effect and greeting based on local time.
  2. Projects & Accessible Modals: Featured project showcase (NUMIFY). Clicking 'View Project' opens a keyboard-accessible modal with specifications and live links.
  3. Filtering: Filter projects by Web or Academic with smooth layout reflow transitions.
  4. Skills & Awards: Interactive SVG logos with brand hover glows and a certificate lightbox viewer.
  5. Theme Toggling: Instant light/dark switch persisted via localStorage.

4. Tools & Technologies Used

Are there difficult tools or frameworks? No. There are zero npm dependencies, no Node.js runtime required, and no build tools.

  • Core Languages: Semantic HTML5, CSS3 Variables & Flex/Grid, Vanilla JavaScript (ES6+).
  • Native Browser APIs: localStorage (theme memory), IntersectionObserver (scroll reveal), requestAnimationFrame (60 FPS smooth animations), navigator.clipboard (copy email), window.matchMedia (reduced motion accessibility).
  • Formats: SVG for vector crispness, WebP for fast image loading.
  • Server Tool: Python 3's built-in http.server for local hosting.

5. Code-Level Defense (If Your Teacher Inspects Code)

1. IIFE & Scope Isolation (Line 5)

Wraps code in an Immediately Invoked Function Expression ((function () { "use strict"; ... })()) to prevent polluting the global namespace.

2. XSS Sanitization (Line 16)

Uses a custom esc() sanitizer replacing < > " ' & to prevent Cross-Site Scripting when injecting HTML.

3. Event Delegation (Line 175)

Uses wrap.addEventListener("click", e => e.target.closest(...)). Instead of hundreds of listeners, a single parent listener handles all clicks efficiently.

4. Smooth Physics (Lerp Math) (Line 615)

Uses Linear Interpolation rx += (x - rx) * 0.18 to give the cursor ring an elastic, natural follow effect with GPU-accelerated translate3d.

5. Accessibility & Focus Trapping (Line 388)

When a modal closes, lastOpener.focus() returns keyboard focus to the exact button that opened it, complying with WCAG accessibility standards.
